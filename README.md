# Waitangi Wheel — Te Awhi

Interactive self-assessment wheel for the 10-week programme. Clients mark six spokes (1–5) at Week 1, Week 5 and Week 10 and see their progress overlaid (● W1, ▲ W5, ■ W10).

- **Clients**: open their personal link — no password. Marks save automatically.
- **Kaimahi/staff**: sign in at `admin.html` — add clients, copy their links, view/print any client's wheel.

## Files

| File | What it is |
|---|---|
| `index.html` | Client wheel (opened via personal link) |
| `admin.html` | Staff admin page |
| `wheel.js` / `style.css` | Shared wheel drawing + styles |
| `config.js` | Supabase URL + anon key (paste yours in) |
| `schema.sql` | Database setup — run once in Supabase |

## Setup (one-time, ~15 minutes)

### 1. Supabase project
1. In the **Te Awhi** organisation on supabase.com → **New project**. Name it `waitangi-wheel`, region **Sydney (ap-southeast-2)**, generate a strong database password (save it somewhere safe — you rarely need it again).
   - Free plan allows 2 *active* projects across your orgs — pause an unused one first if blocked.
2. **SQL Editor → New query** → paste the whole of `schema.sql` → **Run**. You should see "Success".
3. **Authentication → Sign In / Up**: turn **off** "Allow new users to sign up" (staff accounts are created by you, not self-service).
4. **Authentication → Users → Add user → Create new user**: create each staff login (email + password). Tick "Auto confirm".
5. **Project Settings → API**: copy the **Project URL** and the **anon public** key into `config.js`.

### 2. Hosting (GitHub Pages)
1. In the Te-Awhi GitHub org, create a **public** repo called `wheel` (public is required for free Pages; nothing secret lives here — the anon key is public by design).
2. Upload all files in this folder (repo → **Add file → Upload files**).
3. Repo **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. After a minute the app is live at `https://te-awhi.github.io/wheel/`
   - Admin: `https://te-awhi.github.io/wheel/admin.html`
   - Client links are generated by the admin page automatically.

Later, when DNS is sorted, the same repo can serve at `wheel.teawhi.org.nz` (Pages → Custom domain).

## Day-to-day use

1. Kaimahi signs in to the admin page → **Add client** → link is copied to clipboard.
2. Text/email the link to the client (or open it with them in session).
3. Client taps their marks at Week 1, 5 and 10 — everything saves automatically.
4. Kaimahi can **View wheel** any time, and **Print / save as PDF** for the client file.

## Privacy notes

- Client names + ratings are personal information — keep names minimal if possible (first name is enough).
- Personal links act as keys: anyone with a client's link can see that client's wheel. Send links directly to the client only.
- Data is stored in Supabase (region Sydney). Staff access is limited to accounts you create.
- Free plan pauses the project after ~1 week of no use; if the app ever says it can't load, unpause the project in Supabase. For always-on production use, upgrade the Te Awhi org to Pro (US$25/mo).
